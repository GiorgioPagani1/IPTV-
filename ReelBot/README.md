# ReelBot для Android
Приложение для автономного монтажа коротких вертикальных видео из нескольких пользовательских исходников. Интерфейс на русском, без облачных серверов и подписки.

## Возможности
- Выбор до 20 видеоклипов в проводнике Android, добавление фоновой музыки.
- Локальная эвристическая оценка кадров (движение, контраст, экспозиция) и выбор неперекрывающихся фрагментов.
- Динамичная/спокойная нарезка, цель 15 / 30 / 60 секунд.
- Задание монтажу свободным текстом, готовые пресеты, приблизительные склейки по движению/сходству и синхронизация с битом по выбранной музыке.
- Масштабирование с кадрированием в вертикальный Full HD 1080×1920.
- MP4 H.264/AAC, сохранение в Movies/ReelBot через MediaStore, предпросмотр и «Поделиться».

## Монтаж по текстовому заданию
На главном экране есть поле «ЗАДАНИЕ ДЛЯ МОНТАЖА» и четыре готовых примера.
Приложение распознаёт команды по ключевым словам на русском/английском:
- «склейки по движению» — стремится сохранять направление движения между соседними фрагментами;
- «по объекту / по цвету / по композиции» — приблизительно подбирает соседние кадры по визуальному сходству (цвет, раскладка кадра), **не распознаёт конкретные объекты**;
- «монтировать в бит / по музыке / под ритм» — локально декодирует выбранную аудиодорожку, оценивает BPM и выравнивает внутренние точки склейки по найденным музыкальным ударам;
- «динамично / быстрые склейки» или «плавно / спокойный монтаж» — регулирует среднюю длительность фрагментов.

Музыку нужно выбрать отдельно, иначе команда «в бит» не запускается. Если бит недостаточно выражен или формат аудио не поддерживается, приложение прямо сообщает об этом и делает **равномерную нарезку**, без ложного обещания синхронизации. Музыкальная привязка и визуальные оценки приблизительные. Запрос не отправляется в интернет и не обрабатывается большой языковой моделью.

## Установка
GitHub Actions → ReelBot APK → успешный запуск → Artifacts → ReelBot-Android-APK → извлечь app-debug.apk и установить на Android 10+.

## Сборка
Gradle 8.11.1, Android Gradle Plugin 8.10.1, Android SDK 36, JDK 17.
В каталоге ReelBot выполнить gradle :app:assembleDebug.

## Ограничения
MVP — эвристический монтаж по качеству кадров, цветовому сходству и примерному движению, а не смысловой ИИ-режиссёр; не идентифицирует предметы, не удаляет речевые оговорки и не генерирует субтитры. Бит анализируется эвристически и может не подходить к музыке с переменным темпом или нечёткими ударами. Экспорт зависит от поддерживаемого устройством кодека. Перед публикацией результат необходимо проверить. Используйте только музыку с соответствующими правами.
