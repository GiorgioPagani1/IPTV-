# РФ ТВ

Приложение для просмотра общедоступных российских телеканалов на Android и Android TV.

После загрузки исходников GitHub Actions автоматически собирает тестовый APK; результат скачивается в Actions → `Android TV + Phone APK` → Artifacts → `RF-TV-Android-APK`.

Каналы загружаются из открытого каталога iptv-org (`countries/ru.m3u`). Доступность потоков зависит от правообладателей, оператора и страны просмотра; геоблокировки не обходятся.

Android 6+, управление касанием на телефоне или пультом на Android TV.
