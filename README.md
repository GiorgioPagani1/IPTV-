# РФ ТВ 2.2

Минималистичный IPTV-плеер **российских телеканалов** для Android TV / Google TV и Android-телефона.

Или открыть [GitHub Releases](https://github.com/GiorgioPagani1/IPTV-/releases/tag/v2.2.0).

## Возможности

- Полноэкранное прямое телевидение. Панель управления появляется по нажатию и скрывается через 5 секунд; список каналов выезжает слева.
- Короткий каталог узнаваемых российских каналов вместо сотен непонятных записей. Поддерживается поиск и избранное.
- Кнопки переключения, краткая плашка с названием, **↶ возврат к предыдущему каналу**.
- **Телепрограмма сейчас и далее** из свободного XMLTV-источника [FreeEPG](https://free-epg.de/playlists/ru). Загружается отдельно и кешируется на 6 часов; когда нет достоверных данных — название передачи не отображается. Отсутствие EPG не мешает просмотру.
- **Собственный порядок каналов**: удерживайте OK на пульте или строку пальцем, чтобы закрепить канал, сдвинуть выше/ниже, скрыть или вернуть его. Доступ к скрытым каналам находится в боковой панели.
- **Список альтернативных трансляций** у каждого канала. При сбое плеер пробует следующий URL, а недавно неработавшие источники временно становятся последними в очереди.
- **Ручной выбор источника** из контекстного меню. Для каждого эфира показан домен источника и отметка о недавней ошибке.
- **Возобновление просмотра**: открывается последний канал; после сворачивания плеер возобновляет просмотр при возвращении в приложение.
- Избранное и персональный порядок хранятся локально.

## Управление

- Коснитесь видео / OK — показать управление.
- ☰ — открыть боковой список и поиск.
- ◀ / ▶ или CHANNEL UP / DOWN — листать каналы.
- ↶ — вернуться к предыдущему просмотренному каналу.
- Удерживайте строку канала / OK — контекстное меню: закрепить, переместить, скрыть, выбрать источник.
- «Скрытые каналы» в боковой панели — вернуть скрытые пункты.

## Технические особенности и ограничения

Java, Android SDK, Media3 ExoPlayer, GitHub Actions; минимальный Android 6.0.

Источники телеканалов загружаются из общедоступного [iptv-org](https://github.com/iptv-org/iptv). Это **не оператор эфирного телевидения**: открытые URL могут устареть, не отвечать, требовать авторизацию/DRM или блокироваться по географии. Плеер не обходит ограничения и не гарантирует работу всех каналов.

XMLTV-источник — третья сторона: его доступность, актуальность, покрытие каналов и соответствие времени передачи не гарантированы. В приложении EPG необязателен и не препятствует просмотру.

**Debug APK:** автоматические GitHub-сборки подписываются временным ключом, поэтому установка поверх версии с другим ключом может не пройти. В этом случае старую версию нужно удалить, и локальные настройки будут сброшены.
