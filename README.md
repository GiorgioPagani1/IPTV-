## Исправление телепрограммы в версии 2.4

- Главный источник — **EPG.ONE Россия** (`epg.one/ru.xml.gz`), от TeleGuide/EPG.ONE. При недоступности HTTPS пробуется HTTP.
- Резервные варианты — **TeleGuide**, **IPTVX**. FreeEPG оставлен лишь последним резервом.
- **Не только tvg-id:** теперь EPG соотносит каналы по нормализованным русским названиям, английским названиям и распространённым альтернативным именам («Первый», «Россия 1», «ТВЦ», «РБК» и т. д.).
- Программа загружается только при открытии кнопки **▦**, кешируется до 4 часов и отображается в режимах «Сейчас / далее» и «Сетка по времени».
- Кнопка **↻** в окне телепрограммы обновляет EPG вручную, игнорируя возраст кеша.
- При отсутствии данных отображается диагностическое сообщение, вымышленные передачи не подставляются.
- Загрузка XMLTV потоковая: в памяти сохраняются передачи только для каналов из короткого списка, а не все программы на сервере.

### Остальные функции

Только российские телеканалы, избранное, поиск, сортировка и закрепление, скрытие, смена источника трансляции, автоматические резервные потоки, полноэкранный просмотр без фильмов, сериалов, таймлайна и паузы.

### Ограничения

Открытые EPG-сервисы не гарантируют передачу данных для каждого канала; они могут быть недоступны из отдельных сетей и регионов. Источники потокового видео тоже могут ограничивать просмотр. Приложение не обходит платный доступ или DRM. GitHub Actions проверяет сборку APK, но реальный просмотр и покрытие EPG на устройстве требуют теста.

Debug APK может иметь другую подпись относительно старой версии: если Android не обновляет приложение, удалите прежнюю установку и установите новую. Это сбросит локальные настройки.
