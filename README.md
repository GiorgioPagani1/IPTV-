## Новый интерфейс

Референсы: боковой список телеканалов с программой текущего эфира и временная сетка. В плеере **нет отдельной всплывающей плашки при смене канала и нет кнопки «вернуться к предыдущему»**.

- По нажатию на видео или OK появляются компактные кнопки **◀ / ☰ / ▦ / ☆ / ▶**, скрываются через 5 секунд.
- **▦ — Телепрограмма**, также аппаратная кнопка **GUIDE / INFO** на некоторых пультах.
- Телепрограмма открывается **только по запросу**, поверх изображения, и имеет два режима: **«Сейчас и далее»** (список каналов + подробности) и **«Сетка по времени»** (горизонтальная таблица передач с текущим временем).
- **Временная сетка** показывает время начала и окончания и текущую передачу с выделением. Выбор канала из телепрограммы переключает прямой эфир — **видеоархива и перемотки нет**.
- Источник телепрограммы: [FreeEPG XMLTV для России](https://free-epg.de/playlists/ru), обновление с локальным кешем на 6 часов. Если источник недоступен или у канала нет программы, никаких вымышленных передач не отображается.
- Список каналов, поиск, избранное, закрепление, сортировка и скрытие сохраняются.
- Автоматический перебор резервных адресов эфира, ручной выбор и пометка временно неработающих источников сохраняются.

## Управление

- Коснитесь видео или нажмите OK — открыть/скрыть элементы.
- ◀ / ▶ — предыдущий и следующий канал.
- ☰ — список каналов и поиск.
- ▦ — программа на сегодня.
- ☆ — избранное.
- Удерживайте строку / OK в списке — переместить, закрепить, скрыть, выбрать трансляцию.
- В телепрограмме переключайте вкладки «Сейчас и далее» / «Сетка по времени».
- «Назад» закрывает телепрограмму и возвращает эфир.

## Важно

Для каналов используются открытые ссылки iptv-org. Не каждый поток доступен в каждой стране. DRM, авторизация или геоблокировка не обходятся. Данные FreeEPG могут быть неполными, а APK проверен автоматической сборкой, но ещё не протестирован на конкретном устройстве.

Файл собирается GitHub Actions как **debug APK**; если Android сообщает о несовместимой подписи, удалите предыдущую тестовую версию и установите новую. Настройки прежней установки будут потеряны.
