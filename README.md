# РФ ТВ 2.1 — российское IPTV для Android TV и телефона

Бесплатный экспериментальный IPTV-плеер: полноэкранный прямой эфир, управление с пульта или касанием. **Никаких подписок, фильмов, сериалов, паузы и таймлайна.**

## Что нового в 2.1

- Вместо сотен потоков — каталог из **до 31 популярных российских телеканалов**. Показываются только станции с найденными открытыми ссылками. По состоянию на 2 ноября 2026 года в каталоге iptv-org есть ссылки для **29 из 31** выбранных каналов.
- Разные ссылки одного канала сводятся в одну строку; максимум **5 источников** на канал.
- Источники с HTTPS и публичные адреса вещателей имеют преимущество. Последний успешно воспроизводившийся адрес запоминается.
- При ошибке или длительной загрузке (12 секунд) автоматически пробуется следующий адрес **этого же канала**.
- При исчерпании ссылок показывается причина последней ошибки (например, HTTP 403/404, тайм-аут) и предлагается переключить канал самому. Приложение не будет самостоятельно прыгать на другой телеканал.
- Поиск по имени, избранное, логотипы (если имеются в плейлисте), запоминание последнего канала, количество источников у канала.
- Плеер на весь экран, панель кнопок поверх видео автоматически исчезает через 5 секунд, каталог открывается через ☰.
- В заголовке каталога кнопка **↻** — обновить ссылки вручную.

## Скачать тестовый APK

1. Откройте вкладку [Actions](../../actions) этого репозитория.
2. Выберите последнюю успешную сборку **Android TV + Phone APK**.
3. Скачайте `RF-TV-Android-APK` из раздела Artifacts и распакуйте.
4. Установите файл `app-debug.apk` на Android 6+.

Если предыдущий тестовый APK подписан другим debug-ключом, для установки новой версии потребуется удалить предыдущую (при этом локальные избранные каналы сбросятся).

## Ограничения

Это **не телевизионный оператор**. Приложение не гарантирует доступность канала, не обходит геоблокировки, DRM или платную авторизацию. Проверка выполняется при попытке запустить поток, а не заранее для всего каталога. Наличие ссылки не значит, что она воспроизводится в вашей стране.

Список пополняется из общедоступного каталога [iptv-org](https://github.com/iptv-org/iptv) (`https://iptv-org.github.io/iptv/countries/ru.m3u`). У некоторых широко известных станций (включая «Пятый канал» и основной «Матч ТВ») сейчас нет подходящих ссылок в этом открытом каталоге — поэтому приложение не показывает пустые элементы.

## Технологии

Java, Android SDK 35, Media3/ExoPlayer 1.5.1, Gradle 8.7, AGP 8.6.1. GitHub Actions собирает debug APK автоматически при каждом push в main.
